# Core Layer

This folder houses application-wide configurations and helpers:
- `theme/`: App colors, light/dark modes, font sizes, shapes.
- `routing/`: GetX route definitions and paths.
- `network/`: centralized Dio configuration, retry policies, HTTP logs, token interceptors.
- `bindings/`: Global dependency injection bindings.
- `utils/`: Common layout dimensions, string extensions, input formatters.
